## 1. 项目概览

**TermHub** 是一个跨平台 SSH 客户端桌面应用(对标 Xshell/FinalShell 的本地客户端,不是服务端):

- **后端**:Go 1.25 + Wails v3(`v3.0.0-alpha2.122`,beta 版 API)
- **前端**:React 18 + TypeScript + MUI v9 + zustand + xterm v6
- **终端**:xterm.js(WebGL 加速),数据面走 127.0.0.1 本地 WebSocket
- **平台**:Windows(主要验证)/ macOS / Linux

核心能力:SSH 连接管理(密码/私钥/TOFU/保活/断线重连/传输代理/跳板机)、多标签交互终端、双栏文件传输、会话工具(运行状态/流量监控/进程/端口/服务)、文件视图(拖拽上传/右键下载删除)。

### 分层架构(严格遵守)

```
┌───────────────────────────── main.go ─────────────────────────────┐
│ 组装入口:创建领域层实例 → 桥接层 → 注册 7 个 Wails 绑定服务 →      │
│ 事件管线 → 窗口(含退出守卫与窗口关闭钩子)                          │
└───────────────┬──────────────────────────────┬────────────────────┘
                │ 函数调用                       │ 事件 Event.Emit
┌───────────────▼──────────────┐ ┌──────────────▼───────────────────┐
│ internal/sshsvc(领域层)      │ │ internal/bridge(桥接层)           │
│ 纯 Go,不依赖任何 UI/Wails    │ │ Wails 绑定 + WS 终端桥 + 事件     │
│ Manager/RemoteFS/TransferMgr │ │ 只有本包与 main 允许 import Wails │
│ 回调(OnOutput/OnExit...)上抛 │ │ + internal/credstore(钥匙串)      │
└───────────────┬──────────────┘ └───────────────┬───────────────────┘
                │ 绑定调用(控制面)  +  WS 127.0.0.1(数据面)
┌───────────────▼────────────────────────────────▼──────────────────┐
│ frontend/  React 界面                                              │
│ App.tsx(布局/视图模式) → components/ → services/ → bindings/(生成)│
│ store/(zustand 状态) ← Events.On(订阅)                              │
└────────────────────────────────────────────────────────────────────┘
```

**两条通路**:
- **控制面**(低频):前端 → Wails 绑定(Go 服务方法)→ 领域层;事件 → `Events.On` 推送。
- **数据面**(高频):终端输入/输出经 `127.0.0.1:<wsPort>/ws/{sessionID}` 的本地 WebSocket 双向流动(绑定传输 JSON 开销大,不适合终端流)。

| `Run(runID, command, cwd)` | 异步执行:`Windows → cmd /C <command>`,其他 `sh -c`;`cwd` 非空设为工作目录;`cmd.Cancel` 被覆写为**结束整棵进程树**(Windows 用 `taskkill /T /F /PID`) |
| `Cancel(runID)` | 取消运行(close ctx → 触发 Cancel);返回是否找到 |
| `pump(runID, stream, rc)` | 按块读输出回调(保留无换行的进度类输出) |
| `newConsoleReader(rc)` | **输出解码**(平台相关):Windows 按系统 OEM 代码页(经 `GetOEMCP`)用 `golang.org/x/text` 流式解码为 UTF-8(936→GB18030、950→Big5、932→ShiftJIS、949→EUCKR;其它原样),解决 `.bat` 中文输出乱码;非 Windows 原样返回。见 `decode_windows.go` / `decode_other.go` |

## 5. 前端文件详解

### 入口与基础设施

- **main.tsx**:React 入口,StrictMode + ThemeProvider + CssBaseline。
- **theme.ts**:Tokyo Night 暗色主题(background #10121a/#161925,primary #7aa2f7);全局细滚动条;`body userSelect:none`(终端与输入框内单独放开)。
- **types.ts**:线缆类型以 `bindings/` 生成为单一来源,统一导入再导出(Application 层不直接 import bindings 模型);自有类型 `SessionStatus`、`SessionTab{key, sessionId?, wsPort?, cfg, status, fingerprint?, exitReason?}`;`errMsg(err)` 提取可读错误。
- **bindings/**:`wails3 generate bindings` 生成,**勿手改**(models 与 service 调用类)。

### store/

- **appStore.ts**(zustand):全局核心状态。`connections`(localStorage `termhub.connections`,含旧版 proxy→proxyJump 迁移)、`sessions`(标签页列表)、`activeKey`、`dialog`、`hostKeyPrompt`、`deletePrompt`。
  - `init()`:默认一个空白标签页;旧版 localStorage 指纹迁移进钥匙串后剥离。
  - `newTab()` / `setActive()` / `removeTab()`(关最后标签自动补空白页)/ `disconnect()`(后端断开 + 移除标签)/ `reconnect()`(移除旧标签用原配置重连)。
  - `saveConnection()`(去掉密码落 localStorage,返回含密码副本)/ `removeConnection()`(清钥匙串凭据 + `termhub.ftpath.*`/`termhub.fileviewpath.*` 路径记忆/`termhub.ftblacklist.*` 传输黑名单/`termhub.privatecommands.*` 私有命令库)。
  - `connect(conn, passwordOverride?, proxyPasswordOverride?)`:缺密码时从钥匙串取,仍缺则弹补密码框;**活动标签是空白页时在其上建立,否则新建标签**。
  - `establish(cfg, tabKey?)`:调 `api.connect`;`needsHostKeyConfirm` → 存 hostKeyPrompt + 标签转 confirming;成功 → 写入 sessionId/wsPort 转 connected;失败 → exited。
  - `confirmHostKey()`:把指纹写入配置对应字段(target/proxy)→ 存钥匙串 → 重新 establish。
  - `hydrateSecrets()`:从钥匙串填密码与指纹。
  - `markExited(sessionId, reason)`:后端 exit 事件 → 标记标签。

- **transferStore.ts**(zustand):任务列表,由 `termhub:transfer:progress/done` 事件驱动(`upsert` 按 ID 替换或追加;**终态不可被 running 快照覆盖** —— 小文件 `done` 事件可能先于发起绑定返回,否则会永久卡 0%);`upload/download` 发起(**末参 `exclude` 为传输黑名单**,失败以瞬时错误任务展示);`cancel`(本地即时置已取消,防后端任务已结束导致残留)/`dismiss`。
- **notificationStore.ts**(zustand):全局通知队列 `{items:[{id,message,severity}]}`,`notify(msg, severity?, duration=3200)` 入队并定时自动移除、`dismiss(id)`;由 [NotificationCenter.tsx](../frontend/src/components/NotificationCenter.tsx) 渲染。**约定:通知类消息(操作成功/失败等)统一走这里,不再用内嵌提示条。**
- **groupRunStore.ts**(zustand):命令组/单条命令执行引擎。`start(sessionId, kind, groupName, commands)`(kind='group'|'single')按命令文本解析各步类型(见 `commandMetaByCommand`)后顺序执行,失败即停;`cancel()` 终止(置标志 + 调当前步取消函数)、`dismiss()` 关闭;`run` 保存 `{kind,steps:[{index,type,command,status,output,error}],current,status}`。执行细节:常规步 `tools.runCommand`(exec 通道,退出码)、传输步 `runTransferCommand`(等 `transfer:done`)、外部步 `hostCmd.start` + `termhub:hostcmd:done`(退出码,输出流式追加);单次只允许一个运行(正在进行时忽略新启动)。**按需执行**:`arm()` 建 `idle` 态运行(不自动跑)、`toggleStep/setAllSelected` 调 `selected`(默认全选)、`runSelected()` 置 `running` 后仅执行勾选步(跳过未选);步骤类型按命令文本解析。

### services/

- **api.ts**:`connect/disconnect/sessions/quitNow` 包装 TermHubService。
- **files.ts**:两个对象 —— `sftp`(ListDir/Exists/Mkdir/Remove/Upload(exclude)/UploadBytes(base64)/Download(exclude)/Cancel/Transfers)与 `local`(ListDir/Exists/HomeDir/DownloadsDir/ChooseFile/ChooseDirectory)。
- **fileBlacklist.ts**:传输黑名单数据层。localStorage `termhub.ftblacklist.{connId}` = `{local: string[], remote: string[]}`(按连接持久化,删连接时清理);`isExcludedLocal/isExcludedRemote`(命中自身或位于被排除目录之下)、`containsPath`(精确判断,供右键菜单显示加入/移出)、`togglePath`、`load/saveBlacklist`、`connIdForSession`(命令传输只有 sessionId 时反查 connId)。
- **commonCommands.ts / privateCommands.ts**:常用命令数据层。公共库 localStorage `termhub.commoncommands`(全服务器通用)、私有库 `termhub.privatecommands.{connId}`(按连接 id 隔离,`connId` 来自连接配置的 `id`;删连接时清理);两者条目结构一致(命令/描述/类型),`parseCommands` 兼容旧数据(无 `type` 视为常规);`loadCommands/persistCommands`、`loadPrivateCommands/persistPrivateCommands`、`addCommandsToPrivate`(按命令文本去重批量写入、只新增不改源库);`descriptionByCommand/commandMetaByCommand`(命令组「查看」与执行按命令文本反查描述/类型,**只读公共库**)。
- **tools.ts**:`listProcesses/killProcess/listPorts/listSystemInfo/listServices/controlService/getTrafficSnapshot`。
- **terminal.ts**:`TerminalBridge`(见 §6 数据面)。
- **credentials.ts**:12 个钥匙串方法;读失败/未保存**统一降级空串**(前端表现:每次询问密码/重新确认指纹);删除失败静默。
- **clipboard.ts**:SetText/GetText;`GetText` 是 Go 多返回值 → TS 元组解构。
- **hostCmd.ts**:`start(command, cwd)/cancel(runId)` 包装 HostCommandService(宿主机命令;输出/结束经 `termhub:hostcmd:output/done` 事件)。
- **transferCommand.ts**:命令"传输"类型 —— `parseTransferCommand(text)`(语法 `file|dir "<本地绝对路径>" <服务端路径>`,尊重双引号、本地须绝对路径)与 `runTransferCommand(sessionId, text)`(先订阅 `transfer:done` 再发起上传,成功 resolve、失败/取消 reject);执行前经 `connIdForSession` 取该连接黑名单并传本地名单,源文件/目录命中即被后端拒绝。

## 6. 关键机制与数据流

### 连接建立流程(含 TOFU)

```
点卡片/连接按钮 → appStore.connect(cfg)
  → 钥匙串 hydrateSecrets(密码/指纹) → establish
  → api.connect → TermHubService.Connect → Manager.OpenTerminal
      ├─ cfg.TrustedHostKey 为空:握手拿到指纹后主动断开
      │    → ErrHostKeyUnknown → ConnectResult{needsHostKeyConfirm:true}
      │    → 前端 HostKeyDialog 确认 → confirmHostKey 写指纹入配置+钥匙串
      │    → 再次 establish(两阶段)
      └─ 指纹匹配:pty + shell 建立 → SessionID + wsPort
  → 前端建 TerminalView(常驻挂载)→ TerminalBridge 连 ws://127.0.0.1:{port}/ws/{id}
```

### 终端数据面(WS 协议)

| 方向 | 帧类型 | 载荷 |
|---|---|---|
| 前端→后端 | 二进制 | 键盘输入字节 |
| 前端→后端 | 文本 JSON | `{type:'resize', rows, cols}` |
| 后端→前端 | 二进制 | 远端输出(stdout+stderr 合并流) |
| 后端→前端 | 文本 JSON | `{type:'exit', reason}` |

- 会话结束时后端发 exit 帧关 WS → 前端 onExit → markExited 标签转"已退出";同时 `termhub:session:exit` 事件兜底。
- **断线自动重连**:TerminalBridge `onclose`(非主动关闭)→ 指数退避 1s→5s 重连;后端 attach 时回放 64KB 缓冲输出,`onReconnected` 后重新 fit/resize。
- **背压**:有附着连接时后端阻塞写(输出 goroutine 自然限速);无连接暂存缓冲。

### 事件清单(Event.Emit → 前端 Events.On)

| 事件名 | 载荷 | 用途 |
|---|---|---|
| `termhub:session:exit` | `{sessionId, reason}` | 标签转已退出 |
| `termhub:transfer:progress` | TransferInfo | 任务进度(后端已 100ms 节流) |
| `termhub:transfer:done` | TransferInfo | 任务终态(done/error/canceled);App 更新任务并弹右下角通知 |
| `termhub:traffic:sample` | `{sessionId, samples[]}` | 流量曲线(每 2s) |
| `termhub:hostcmd:output` | `{runId, stream, data}` | 宿主机命令输出(stdout/stderr,按块) |
| `termhub:hostcmd:done` | `{runId, exitCode, error}` | 宿主机命令结束(退出码;精确判定完成) |
| `termhub:quit:prompt` | `{count}` | 退出前有传输任务提示确认 |

### 退出保护(双重拦截)

1. `Options.ShouldQuit = quitGuard.ShouldQuit`:有任务 → 返回 false + 发 quit:prompt 事件。
2. **Windows 关窗口不经过 ShouldQuit** → `win.RegisterHook(events.Common.WindowClosing)`:有任务且未允许 → `e.Cancel()` + 发事件。
3. 前端 ConfirmDialog 确认 → `api.quitNow()` → `QuitGuard.QuitNow()` 置 allow + `application.Quit()`。

### 会话生命周期与关闭顺序

```
等待 goroutine(sess.Wait 返回)是唯一清理路径:
  remove(池) → ts.Close() → 判定 reason → onExit 回调
TerminalSession.Close 顺序(死锁回归点):
  sess → client(先,让 SFTP 收包 goroutine 随连接 EOF 退出)→ sftp → jump(最后,目标隧道在其上)
```

### 拖拽上传(文件视图)

网页拿不到系统路径 → 读文件内容 base64 → `SftpService.UploadBytes`([]byte 跨绑定自动 base64)→ TransferManager 直接写远端(100MB 上限,大文件提示走文件传输);目录拖入时 `webkitRelativePath` 保留层级(relDir)。

### 路径记忆

- 文件传输:`localStorage['termhub.ftpath.' + connId]` = `{local, remote}`;初始恢复完成(`initDone`)前不挂载面板防覆盖。
- 文件视图:`localStorage['termhub.fileviewpath.' + connId]` = 远端目录字符串。
- 删除连接时两者一并清理(appStore.removeConnection);私有命令库 `termhub.privatecommands.{connId}` 同样按连接清理。

## 8. 约定与坑(修改代码前必读)

1. **分层铁律**:sshsvc 不 import Wails/前端;只有 bridge 与 main 可以;前端 services 不直接 import bindings 之外的后端概念。
2. **绑定生成**:改任何 Go 服务方法签名后必须重跑 `wails3 generate bindings -d frontend/bindings -ts -i -clean=true`,否则 tsc 报错;`[]byte` 跨绑定是 base64 string;Go 多返回值在 TS 是元组。
3. **MUI v9 API 变化**:`InputProps`→`slotProps`(input/htmlInput/tooltip/list)、图标改名(ErrorOutline→ErrorOutlineOutlined、DeleteOutline→Delete)、`MenuListProps`→`slotProps.list`;`MuiBadge` 类名选择器失效(徽标手绘);`sx` 数值会 ×8px(gap 用字符串);**Stack 不接受 `justifyContent/alignItems` 直接属性、Typography 不接受 `fontWeight` 直接属性**(v9 移除了系统属性,一律写进 `sx`;direction/spacing 仍是 Stack 直接属性)。
4. **终端历史不丢**:会话视图必须常驻挂载(display:none 切换),任何"提前 return 卸载视图树"的改动都会复现切标签清历史;隐藏态 fit/resize 有守卫,向 pty 发 0 尺寸会出问题。
5. **SFTP 性能**:保持 `UseConcurrentWrites(true)` 与 512KB 拷贝缓冲;x/crypto/ssh v0.55 不支持压缩。
6. **Close 顺序**:client 必须比 sftp 先关(反序死锁),jump 最后关。
7. **测试注意**:测试服务器 map 随机遍历,命令按 key 长度降序匹配;完成回调必须先于任务发起注册(小文件瞬时完成事件丢失);`taskkill` 冒烟测试只杀自己启动的 PID。
8. **安全白名单**:服务名 `^[A-Za-z0-9@._:-]+$`、kill 信号白名单、PID≥1、进程/端口查询只读命令。
9. **事件订阅清理**:组件卸载必须 off(Events.On 返回 unsubscribe);TrafficPanel 用 alive 标志防卸载后 setState。
10. **拖放**:任何新增拖放区域必须 stopPropagation,Wails 运行时 document 级监听会把 dropEffect 置 none 取消拖放。
11. **注释风格**:中文注释,解释"为什么"优先于"是什么";导出符号必须有文档注释。
12. **TS 5.2.2 扫描器坑**:三元表达式 `) : (` 之后**紧跟 `{/* */}` 形式的 JSX 注释再跟标签**会解析报错(TS1005/TS1382,报错位置在注释下一行,极具迷惑性;括号全角/半角无关),该位置一律用 `//` 行注释。JSX 注释在普通子节点位置正常。
13. **滚动容器**:表格类面板的 TableContainer 用 `position:'absolute', inset:0, overflow:'auto'` 铺满相对定位父盒 —— 不要用 `height:'100%'`(嵌套 flex 链上百分比高度解析不可靠,会"列表超出无滚动条");行多出垂直滚动条,列宽总宽超出出横向滚动条。
14. **表格约定**:各表格统一 `tableLayout:'fixed'` + 表头设明确宽度(固定 px 或百分比;未设宽的列吃剩余空间);**表头与正文一律左对齐**(不用 `align="right/center"`)。避免用 `width:'100%'` 撑列(固定布局下会把其它列压扁)。

## 10. 新增功能开发流程(按链路走,缺一不可)

### A. 新增一个"会话工具面板"(最典型全栈链路)

1. **领域层** `internal/sshsvc/`:新文件(如 `diskio.go`)或在既有文件加查询方法 —— 经 `ts.Exec` 在既有会话 SSH 连接上另开通道执行命令(不影响交互终端),解析成结构体;补单测 `*_test.go`(复用内存 SSH 服务器基建,夹具验证解析器)。
2. **桥接层** `internal/bridge/tool_service.go`:加直通绑定方法(仅转发领域层,不写逻辑)。
3. **重新生成绑定**(必须):`wails3 generate bindings -d frontend/bindings -ts -i -clean=true`。
4. **前端服务** `frontend/src/services/tools.ts`:加封装方法。
5. **新组件** `frontend/src/components/tools/XxxPanel.tsx`:参考 [ProcessPanel.tsx](../frontend/src/components/tools/ProcessPanel.tsx) 结构 —— 工具栏(搜索 + 刷新)、TableContainer 绝对定位铺满(§8.13)、右键菜单 + ConfirmDialog、错误/加载态。
6. **注册面板** [ToolsPanel.tsx](../frontend/src/components/tools/ToolsPanel.tsx):`ToolKind` 联合类型加值 + `TOOLS` 数组(图标/标签/顺序)+ `PANELS` 映射。
7. **工具栏入口** [App.tsx](../frontend/src/App.tsx):`ViewMode` 联合类型加值 + 工具栏 ToggleButton。
8. **验证**:`cd frontend && npm run build` → `wails3 build` → 冒烟。
9. **收尾**:changelog(**当天真实日期,先 `date` 确认**) + CLAUDE.md 同步(§2 表、§4/§5 文件详解、§9 如有新症状)。

### B. 新增一个 Go 绑定方法(如新连接操作/新文件操作)

1. sshsvc 领域层实现(纯 Go,不 import Wails)→ 2. 对应 bridge 服务方法(直通)→ 3. 重跑 generate bindings → 4. 前端 `services/*.ts` 封装 → 5. 验证 + 收尾同上。

### C. 新增一个事件(后端 → 前端推送)

1. bridge 内某文件:事件名常量 + `func init(){ application.RegisterEvent[载荷类型](事件名) }`。
2. [main.go](../main.go):领域回调 → `app.Event.Emit(事件名, 载荷)` 接线。
3. 前端 `Events.On('termhub:xxx')` 订阅(**组件卸载必须调用返回的 unsubscribe**)。
4. 验证 + 收尾同上;文档同步 §6 事件清单。

### D. 新增一个连接配置字段

1. [config.go](../internal/sshsvc/config.go) `ConnectionConfig` 加字段(JSON tag 即前端接口,可选字段加 `omitempty`)→ 2. 重跑 generate bindings → 3. [ConnectionDialog.tsx](../frontend/src/components/ConnectionDialog.tsx) 表单 + `validate/buildCfg` + 展示处([ServerGrid.tsx](../frontend/src/components/ServerGrid.tsx) 卡片等)→ 4. 旧数据兼容:如改动语义需在 [appStore.ts](../frontend/src/store/appStore.ts) `loadConnections` 做迁移 → 5. 验证 + 收尾同上。

### E. 新增纯前端视图(不涉及 Go)

1. 组件放 `frontend/src/components/` 对应子目录 → 2. 在 [App.tsx](../frontend/src/App.tsx) 接入(ViewMode/布局)→ 3. `npm run build` 验证 → 4. 收尾同上。注意 §8 全部坑(MUI v9 API、TS 5.2.2 注释坑、滚动容器、拖放 stopPropagation)。
